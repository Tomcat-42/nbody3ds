# nbody3ds

<img src="assets/nbody3ds.png" alt="nbody3ds icon" width="96">

Gravitational n-body simulation running on Nintendo 3DS.

## Build

Requires [devkitPro](https://devkitpro.org/) with devkitARM, libctru, and citro3d.

```
make
```

## Controls

| Input | Action |
|-------|--------|
| Circle Pad | Camera orbit |
| L / R | Zoom |
| A | Add body |
| D-Pad Up/Down | +/- 10 bodies |
| D-Pad Left/Right | +/- 50 bodies |
| B | Reset |
| START | Exit |
